# OSCAR UI Design System

The dashboard follows one consistent dark research-terminal language inspired by the selected reference direction. It is reference-inspired, not a pixel-for-pixel copy.

## Visual principles

- Calm, information-dense but never crowded.
- One primary action per view.
- Candidate selection first; trade details second.
- No decorative charts or metrics without a decision purpose.
- Real and sample data are visually distinct.

## System tokens

- Background: deep navy/blue-black.
- Panels: slightly lighter navy with subtle borders.
- Primary accent: restrained mint/teal for active, positive and confirmed states.
- Secondary accent: cool blue for setup categories and neutral emphasis.
- Risk: muted red used only for stop-loss, invalidation and warnings.
- Text: high-contrast cool white; secondary text uses slate blue-gray.
- Borders: thin, low-contrast blue-gray lines.
- Radius: 8–12px; no excessive pills or floating cards.
- Spacing: 8px base rhythm; generous section spacing.
- Typography: compact sans-serif, strong numeric alignment, restrained weights.

## Components

- Persistent narrow sidebar with four destinations: Stock selection, Watchlist, Paper trades, Research.
- Quiet top bar with date, data status and one utility action.
- Four small summary metrics, never oversized hero cards.
- Segmented filters with one selected state.
- Ranked table with right-aligned numbers and a single selected row.
- Detail panel with price, chart, level markers, trade plan and reason codes.
- Status labels: Watch, Review, Triggered, Extended and Invalid.
- No buy/sell CTA in the research version; Watch and Paper-trade actions only.

## Consistency rule

Every future OSCAR screen must reuse these tokens and components. Do not introduce a new color, card style, radius, chart treatment or navigation pattern for an individual feature.
